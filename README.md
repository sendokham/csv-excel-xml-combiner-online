## Core Browser Tools

- **[Excel Online (No Login)](https://sheetcombine.com/excel-online/)** — Instant browser spreadsheet editor with formula bar, cell styling, and styled `.xlsx` export.
- **[Merge Multiple CSV Files Online](https://sheetcombine.com/merge-csv-files-online/)** — Append monthly exports vertically or join tabs horizontally by ID without writing `#N/A`-prone lookup formulas.
- **[XML to CSV & Excel Converter](https://sheetcombine.com/xml-to-csv/)** — Auto-detects repeating XML tags (`<row>`, `<item>`, `<book>`, `<product>`), attributes (`@id`), and CDATA blocks.
- **[JSON & NDJSON to CSV Converter](https://sheetcombine.com/json-to-csv/)** — Flatten API arrays and logs into RFC-4180 CSV or semicolon CSV for European Excel.
- **[Excel & CSV to JSON Converter](https://sheetcombine.com/excel-to-json/)** — Convert workbooks into clean deduplicated JSON arrays, JSONL, YAML, and SQL `INSERT INTO` scripts.
- **[VLOOKUP & XLOOKUP Multiple Criteria](https://sheetcombine.com/vlookup-multiple-criteria/)** — Match rows across 2+ keys visually or generate clean `XLOOKUP` / `INDEX-MATCH` / `SUMIFS` formulas.
- **[CSV Cleaner & Leading Zero Preserver](https://sheetcombine.com/clean-csv/)** — Trim spaces, deduplicate rows, and export CSV/XLSX without destroying `02134` ZIP codes.
